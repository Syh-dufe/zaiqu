# 混合需求冲击HAPPO基线

用户已批准：正常训练HAPPO、原完整实时策略、混合冲击训练HAPPO最终在共同新路径比较。本阶段只启动五种子纯HAPPO训练，不调用API，不开始最终测试。

## 固定设计

- 种子11..15从头训练，全保留，不按灾情成绩筛选。旧11..20模型与冻结作者文件不改。
- 每次训练reset等概率选正常、single、sustained、double、drop五种情景，各20%。基础需求仍原Merton生成器；只替换进程内get_training_data/get_eval_data，不提供冲击标签、通知或报告给actor，actor7维、critic21维、原0.5自身+0.5系统平均奖励保持。
- first start零基索引50..90；single与drop上涨15..25期、倍率1.2..1.8；sustained上涨40..60期、倍率1.1..1.5；double两个15..25期上涨段，中间间隔20..35期、倍率各1.2..1.8；drop上涨后连续30..50期倍率0.3..0.8。正增向上取整截断20，下降向下取整。参数抽样均为区间均匀分布，整数含两端。最长事件不得超出200期。
- 混合验证集100条，五类各20条，用独立登记随机种子20272011生成，排除所有可提取历史base/shock路径与原20正常验证路径、验证内部重复。固定顺序生成，不依据成本选择。此集只选模型，不作为最终测试。
- 训练使用原5轨迹、200期、默认超参、每seed3m上限、patience40与原经验稳定条件；serial并发1。原scheduled-best选取规则保持，验证内容改为平衡混合集，因此模型选择目标与原正常验证不同，必须披露。
- 训练每次生成的实际轨迹与基础轨迹、情景参数记录jsonl；发现与验证序列精确碰撞则按同类型重抽，不共享验证样本。训练集没有现实标定，不称真实灾害预测。
- 保存完整曲线/快照/best/final；完成后重新加载best/final复现混合验证成本、参数匹配与稳定性。早停不等于收敛。
- 本阶段验证集合和预算一经登记不得按成绩改。最终比较另冻结生成未见路径，披露LLM信息/预测计算与冲击训练费用差异。不得将训练增加视为等总计算预算。
- 输出results/happo_mixed_shock/formal_v1，子曲线mixed_shock_seedN_v1。故障保存原始输出并停止，不自动重跑。

## 风险与范围

验证100轨迹使单次模型选择评估计算量高于原20轨迹；步数上限相同并不表示墙钟相同。需求采样改变随机流，相同模型seed不保证相同初始actor参数（作者先建立环境再初始化网络）。通知/全局报告仍是实时方案额外信息，不混入本基线训练。
