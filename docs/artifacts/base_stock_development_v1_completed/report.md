## 信息与原文适配

主策略因果保留上一期本地需求：下游为外部需求，其余节点为下游订单。原actor本来也观察这些值。库存位置为本地库存＋已发在途＋本地台账未发订单－本地欠货；订单转入在途后从未发台账移除，邻居欠货仅用于审计，不进入决策。

原LLM三期外部报告只含均值，不能恢复原始方差。因此均值重复版本单列近似诊断，不称严格公式复现，也不代表实际新增的中上游报告机制。LLM还使用额外通知、全局状态与预测计算，不能称完全相同信息系统。

Liu附录D指定H=40、总体方差及目标公式。初始化、ceil整数动作与未发台账是明确的代码适配；本研究使用开发择参，区别于原文测试择参。不能称作者官方Base-stock代码。
