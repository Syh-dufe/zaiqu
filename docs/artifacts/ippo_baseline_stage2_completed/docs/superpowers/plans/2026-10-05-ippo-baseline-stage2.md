# IPPO五种子正常训练实施计划

**目标：** 为投稿准备与冻结HAPPO训练条件相匹配的IPPO模型，保留全部五种子和停止原因。按executing-plans依次执行，用户已授权，无需再次审批。

**架构：** 不修改阶段1适配器或任何作者源码。新增独立驱动和完工审核，训练继续调用已验证的IPPO适配器，两个进程并发，其余排队。无API。

## 固定训练协议

- seeds11—15，每个从头训练，名称ippo_seed{seed}_formal_v1；5000步试运行仅为实现检查，不续训、不参与种子选择。
- 原三级库存、正常Merton需求、动作0—20、提前期4、200期、5条采样轨迹、原20条正常验证需求；无灾情输入。
- 默认网络/优化器/归一化/GAE等参数与已有同seed HAPPO一致；训练奖励保留0.5自身+0.5系统平均。仅局部critic和全1 factor构成算法差异。
- 每种子上限300万环境步、patience40、until-stable。至少10万步、相邻两组各10次定期评估成本中位数和最佳成本绝对相对变化均≤1%、最近10次CV≤5%才记录经验稳定。不得放宽。
- 保留原正常验证选择模型，初始评估和最终额外评估不进入官方best选择；经验平台异常发生在原save分支前，触发该异常的评估亦排除。根据实际模型参数哈希确认保存best对应快照，并重载best/final重新评估原20正常路径。
- 不稳定种子依然保留；原早停或预算耗尽不等于收敛。只记录正常训练成本，不进行灾情排名或超参数选择。相同种子不保证两算法使用相同随机流，因为网络维度/更新路径不同。
- 最大并发2；任一训练/哈希/审核失败即停止派发后续任务，已经启动的另一任务可正常收尾并保存。失败不自动重跑、不覆盖。唯一驱动启动锁和每任务已有输出检查。
- 最大总预算1500万环境步；实际时间、步数和停止原因完整记录。没有LLM请求。

## 公平性与范围

HAPPO五模型仍冻结，IPPO的actor与其使用同样局部观测；critic信息不同属于算法定义。原实时LLM在灾情时另有定期报告、通知和预测计算，后续比较必须明示该额外信息与计算。此阶段只训练正常需求基线；不会声称本项目IPPO是作者官方实现或论文精确复现。

正式灾情比较不复用旧确认作为未见测试：所有方法和传统策略参数冻结后另登记/生成并查重新路径，使用相同输入做配对比较。当前仅准备IPPO；MAPPO、传统策略及消融按路线单独登记，不默认启动。
