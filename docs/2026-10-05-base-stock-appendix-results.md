# Base-stock追加比较：复用共同确认路径

## 范围与来源

按用户要求，复用既有三方法共同确认的全部50个最终成功任务、1200回合、720000节点期。没有重新训练HAPPO或IPPO，没有重新调用实时LLM，也没有生成新需求路径。最终任务标签由原完成摘要及SHA校验确定，包含充值后恢复完成的任务；原始失败记录和费用保留。

新增Base-stock的z=2与z=8各80回合，合计160回合、96000节点期。本次API调用为0，运行与审核耗时约82.65秒。历史三方法实验的1713次HTTP请求与6234697 tokens单列为历史开销，不是本次新增费用。

z=2由此前独立的开发输入扫描选定，本轮没有重新选择z；z=8保留为参考。全部10批、四类冲击、五个正常训练模型均保留。两种确定性Base-stock各只有40个冲击路径案例，不拥有训练种子；统计配对时的模型轴广播不增加独立需求样本数。

这是已暴露共同确认路径上的**事后追加基线比较**，不是新一轮前瞻独立确认。此前准备的全新共同确认没有登记、生成输入或启动，按用户要求改为本追加方案。

## 成本结果

成本为200期、3节点的平均I+B，越低越好。三模型方法沿用原结果；Base-stock在完全相同的输入上新增计算。

| 方法 | 正常平均成本 | 冲击平均成本 |
|---|---:|---:|
| HAPPO | 18.42770 | 20.74277 |
| IPPO | 20.20625 | 22.49753 |
| 原实时LLM＋HAPPO | 18.42770 | **20.24203** |
| Base-stock，z=2 | **18.05604** | 20.53671 |
| Base-stock，z=8 | 27.99483 | 32.89579 |

实时LLM＋HAPPO相对z=2的冲击成本低1.43%，配对差异−0.294675，描述性97.5%交叉重采样区间为[−2.885995, 2.474169]，跨零。200个模型×路径配对中94个成本改善、106个退化；不能据均值声称稳定或显著优于z=2。相对参考z=8差异为−12.653758，描述性95%区间[−15.826188, −9.306501]；较强参考结果不能替代与开发选定z=2的比较。

## 实现与审核

Base-stock沿用40期已完成本地需求历史、初始40个10、提前期4、本地未发货账本、原NumPy均值与总体方差，以及ceil和动作[0,20]截断。未来事件类型、结束时间和未来需求不传入策略。每个回合独立重建库存、账本、订货目标、动作与成本；160回合未出现NumPy与独立标量计算的离散边界差异。

全部50个历史成功任务重新逐期审核，复制文件逐字节SHA一致；原来源、源码、模型及输入哈希保持不变。20个Base-stock批任务完成后再审核，总比较1360回合、816000唯一节点期。联网在追加运行中被禁止。历史失败尝试、调用记录、原始状态与全部不利结果保留。

独立只读复核另核对533个原来源SHA、519个历史复制文件字节、50个最终标签，三种原模型方法的正常/冲击摘要与旧结果精确相同；重新从全部96000行CSV计算Base-stock成本，并核对32000行节点0需求与原输入。复核无阻断问题；区间范围与统计标签已核对，复核者没有再执行bootstrap。

LLM使用额外通知、全局状态及预测计算；本比较评价部署系统，不单独证明LLM语义贡献或等信息、等计算预算优势。区间采用20000次模型/路径交叉重采样、seed20271651，均作为本追加比较的探索性描述。
