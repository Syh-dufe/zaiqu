# 非平稳Base-stock基线设定计划

> 执行时使用 executing-plans，按阶段推进；本文件仅登记研究计划，不启动训练、仿真或API任务。

**目标：** 建立基于Liu附录D、定义可复核且参数选择独立于测试的传统库存基线。

**架构：** 在独立目录实现策略、开发择参、登记驱动和审核。作者环境、原HAPPO/IPPO模型、原实时LLM和历史冻结产物均保持原样。

**技术：** 项目现有Python/NumPy/PyTorch环境；Base-stock本身不需要神经网络训练或API。

## 依据和定位

原文附录D：https://journals.sagepub.com/doi/suppl/10.1177/10591478241305863/suppl_file/sj-pdf-1-pao-10.1177_10591478241305863.pdf

原文明确目标S=L*mean+z*sqrt(L*variance)、总体方差分母H、H=40，并在测试需求上选z。本研究改为开发数据选择并冻结，披露该差异。z=8沿用本项目既有参考实现，不称原文指定的最优值。初始历史、库存位置完整代码和离散取整不能称作者官方实现。

## 阶段1：原文及环境时序核对

- [ ] 记录附录D公式、参数依据与未说明事项。
- [ ] 逐项追踪环境reset/step/observation中的到货、下游订单、发货、欠货和决策顺序。
- [ ] 绘制库存位置台账：现有库存、已发在途、未发未收订单、本节点欠货；每笔未收订单只计一次。通过变量语义确定主口径，不按性能选择口径。
- [ ] 核对节点实际可见本地需求及报告字段。需要完整40期方差的算法不能由3期均值重复填充冒充精确方差。
- [ ] 写定信息协议：论文本地历史版本与报告约束版本如信息不同则单独标注。报告不足以提供精确方差时，不新增独占信息；可实现有标签的报告近似版本，但不得称原公式严格复现。

## 阶段2：冻结策略定义

- [ ] 主参考配置H=40、L=4、z=8、动作0..20、原库存成本规则。
- [ ] 下游历史使用已可见外部需求；中上游使用决策前已知下游订单，不使用未来需求/冲击倍率/结束时间。
- [ ] 初始历史主版本40个10，明确本研究假设；敏感性版本使用与测试独立的正常开发历史，来源路径和SHA登记。
- [ ] 订货拟采用ceil(S-IP)截断0..20；仅在环境时序核对完成后定稿。floor版本作离散化敏感性，不依据测试排名更换主版本。
- [ ] 每回合清空历史；不与其他测试回合共享状态。
