# TimesFM预测试用实施计划

**Goal:** 在48个预定开发时点对比冻结TimesFM与原Merton、趋势和朴素预测。

**Architecture:** 独立适配器读取已送达报告块，输出点预测。物理环境与决策模型不改。

**Tech Stack:** Python3.12、现有torch2.14.1 CPU、独立timesfm2.0.2依赖、官方2.5权重。

- [ ] 获取并冻结依赖、官方权重，核对版本与接口，检查资源。
- [ ] 实现报告输入与预测时点登记，检查无未来输入、48身份唯一。
- [ ] 实现独立预测器与原Merton点预测/趋势/朴素对照。
- [ ] 首次推理前保存源码、协议、输入、依赖、权重hash。
- [ ] 运行全部48事件，保存原输出及不利结果；接口错误停止诊断。
- [ ] 独立从逐期预测重算评价、哈希核验不变，写完整报告。
- [ ] 按固定门槛判断是否值得另行登记路径构造与闭环开发。

本实验不运行单元测试或付费API；所列检查属于实验输入与结果核验。不得修改任何既有冻结实验文件。
