# Poisson trained HAPPO versus stationary Base-stock

User authorized proceeding after the ten Poisson10 HAPPO models completed. This stage compares all ten actual saved-best policies against a new stationary Base-stock reference; it does not restart training or paused API jobs. API budget zero.

## Method and information
Use exactly the frozen training environment: three echelons, lambda10, horizon200, zero initial inventory/backlog/pipeline, lead2/4, actions0..20, holding[1,1,1], backlog cost[1,0,0]. Cost is total realized unblended cost divided by 600 node-periods. Preserve all seeds11..15; none excluded for instability. Models are selected only by previous normal validation. Reproduce each saved best on original twenty validation paths before any holdout.

Base-stock is a stationary constant installation target, not the earlier rolling H40/z heuristic. Inventory position before the current simultaneous orders is on-hand + shipped pipeline + own supplier-unshipped orders - own backlog. Own supplier-unshipped ledger obeys outstanding_next=outstanding+order-new_shipment and equals supplier backlog in a serial network; the top external source never backlogs. Observe realized shipments after each transition, without future demand. Order is clip(ceil(target-position),0,20). All state variables and targets are integers, so ceil is exact.

## Parameter calibration
Appendix E motivates echelon target ranges. For each lead L, stage i=1..3 and review allowance r in {0,1}, use Poisson mean 10*i*(L+r). Lower quantile probability=(4-i)/4; upper=(4-i)/(5-i), h=[1,1,1], b1=1. Enumerate all integer echelon targets between max(0,ppf(lower)-1) and ppf(upper), inclusive, retaining nondecreasing targets. Convert to installation targets by differences. Pool/deduplicate both r grids; r=1 is our explicit review-period sensitivity because all decisions precede current unknown demand. This enlarged finite search addresses timing/capacity adaptation; it is not a certified optimum. The r=0 subset follows the paper-inspired bound computation. Do not reuse the paper's lambda-uncertain numeric stock targets.

Score every candidate on all twenty already-reserved baseline_development paths, using realized 200-period raw costs and identical empty starts. Select minimum mean; exact tie lexicographically smaller installation target. Keep every candidate score and the r=0 best. Freeze selection bytes before holdout generation. No parameter updates based on holdout.
