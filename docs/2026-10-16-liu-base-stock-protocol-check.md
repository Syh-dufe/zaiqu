# Liu原文Base-stock比较合同复核

核对来源：正式论文第3.3节、第3.4.3节，以及官方E-Companion附录D第ec5页（PDF第5页）。

- 正式论文：https://journals.sagepub.com/doi/10.1177/10591478241305863
- 官方附录：https://journals.sagepub.com/doi/suppl/10.1177/10591478241305863/suppl_file/sj-pdf-1-pao-10.1177_10591478241305863.pdf

## 原文做法

1. 串联系统使用非平稳Base-stock（Neale与Willems思路）和非平稳(s,S)作为启发式基线，另比较PPO。典型比较覆盖3/4/5级、Merton及真实需求、有无固定成本；评价系统成本与订单波动。
2. 每节点根据过去H期本地需求计算滚动均值与总体方差。附录D明确在T=200设置下通过实验选择H=40。
3. 目标为L乘滚动均值，加z乘提前期需求标准差，即S=L*mean+z*sqrt(L*variance)。
4. 附录D明确在较宽范围枚举z，用测试需求上的总体成本选取最优值。图D.1的Merton、三级、无固定成本示例确实选z=8。附录文字没有给出可一概认定适用于所有实验的统一z=8，也没有把全部搜索网格逐项列为协议。
5. 正文说明评价20条需求轨迹；HAPPO与PPO各重复训练10次，报告均值/区间；启发式在20路径上评价一次，不复制10个所谓训练种子。

## 与本项目区分

本项目旧z=2是另行开发数据选择，不是原文参数复现；旧z8参考有原文该示例依据，但不是通用最优。原文直接用测试需求选择z，本项目若要独立泛化评价，应在新训练/开发需求上择参，冻结后测试；若同测试路径扫描，只能明确报告测试内最优或事后描述，不当独立确认。

此前项目部分文档写“z=8不称原文明确指定最优值”不够准确。准确说法是“原文图D.1示例明确z=8最优；不代表其他路径或本文突发情境的最优值”。旧冻结材料保留，通过本复核说明纠正来源事实，不改变旧运行参数或成绩。

原文目标公式不等于提供完整官方可执行Base-stock代码。原始历史初始化、离散动作取整、动作截断及未发货账本仍需在本项目实现中单独登记，不能凭公式声称代码逐项一致。
