# Sundial固定路径的Base-stock追加比较

## 设置与范围

用户要求在Sundial已有固定路径上补齐传统基线。仅新增开发选定z=2的滚动Base-stock，40期已完成本地需求历史、初始化40个10、提前期4、总体方差、ceil、动作0..20。复用原episode与policy，无训练，无API，不在当前路径调参。库存位置包含现货、已发在途、台账未发订单并减自身欠货，订单转入在途时移出台账。

输入为results/submission_required/v1/inputs/confirmation01_main.json前三类single/sustained/double，全部新策略与缓存对照逐期输入相同。每类正常/冲击各一回合，新增6回合3600节点期。确定性策略没有训练种子，不重复五次制造样本。

纯HAPPO从原submission_required任务复用，完整Merton从guard_pool开发任务复用，Sundial从六规则及其扩展任务复用。五个模型11..15全部保留，90个缓存回合均重新逐期复算成本和需求。旧方法没有重跑或增加LLM费用。

## 证据边界

- 本次是三条已暴露开发需求上的事后追加，不是独立确认；三场景也是历史四场景结果出来后确定的后续范围。
- 每场景仅一条物理需求，模型种子不是独立需求路径，不报告显著性结论。Base-stock在逐模型表中重复值只为配对展示，不增加样本量。
- Merton旧版规则上限4条，Sundial6条；本表不隔离预测器贡献。
- Base-stock按本地已完成需求更新目标，LLM有额外报告、通知、全局状态与预测计算，不称等信息/等计算。
- 本实现是根据原文思路的适配，不称作者官方Base-stock代码，不能声称本配置是当前新路径上的最优Base-stock。
- 当前3参数成本适配层仍在另一批新路径留出评估，没有加入本表，也未被本任务修改或停止。
