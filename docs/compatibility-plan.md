# Emergency Compatibility Implementation Plan

**Goal:** 将官方三级库存问题解释为灾区物资补给，保持计算规则完全复用官方实现。

**Architecture:** 独立启动器使用 runpy 执行固定版本官方 train_env.py，只设置场景和实验名称，官方源码与原论文正在运行的实验均不修改。参数透传允许后续指定小预算，默认预算与早停均沿用官方配置。

**Tech Stack:** Python 标准库启动器；训练依赖来自现有虚拟环境与官方仓库。

- [x] 添加中文说明：节点含义、原规则边界、查看与训练命令、输出位置、旧实验保留。
